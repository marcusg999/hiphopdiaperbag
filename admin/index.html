    What this is

    Every word and image on the landing page lives in content.json. Edit here, hit Preview on the page to see it on the real site without saving anything, then Export to download the new content.json and drop it in the project folder — or use the optional GitHub panel at the bottom to publish straight from this browser.

    In body copy you may use <em>, <b> and <br>. Nothing else is treated as markup. In the small uppercase lines, a slash / becomes the grey divider.

    Commit straight to GitHub

    Optional. Export above works with no token and no account. This panel only exists so you can skip the download-and-copy step: it commits content.json and any changed images to marcusg999/hiphopdiaperbag on main, and GitHub Pages rebuilds by itself.

    Paste a fine-grained personal access token with Contents: Read and write on that one repository. Make it short-lived.

    The token is kept in this browser's localStorage and nowhere else. It is never written into content.json, never committed, never sent anywhere but api.github.com. On a shared machine, hit Forget token when you are done.
